Jinja2 templates for all user-facing pages. Organized by blueprint: club pages, admin pages, auth pages, and player pages. All extend `base.html` which provides the Bootstrap 5.3 layout, navbar, flash messages, and footer.

## Summary

- `base.html` — Base layout: Bootstrap 5.3 CDN, dark navbar with club search form, auth status indicator (server credentials, sync status, OAuth login), flash messages, content block, footer.
- `index.html` — Homepage: hero section with club slug search form and setup warning banner.
- `club/_nav.html` — Partial: club sub-navigation tabs (overview, members, tournaments, leaderboard, matchups, attendance, records). Locked tabs shown when unauthenticated.
- `club/overview.html` — Club overview page: stat cards (members, matches, country flag, founded date), detail table.
- `club/members.html` — Member list table: username, title badge, rating, activity badge, joined date.
- `club/tournaments.html` — Tournament history table: name, format badge, status badge, players, winner, score, dates.
- `club/leaderboard.html` — Leaderboard table: rank, player, tournaments played, total score, avg score, wins. Filterable by year/month. Medal emojis for top 3.
- `club/matchups.html` — Head-to-head matchups table: player A, wins A, draws, wins B, player B, total games, last played. Filterable by last N tournaments.
- `club/attendance.html` — Attendance table: player, played/total, progress bar with percentage, current streak, best streak. Filterable by last N tournaments.
- `club/records.html` — Club records cards: category, value, player, detail, date. Filterable by last N tournaments.
- `player/rating_history.html` — Player rating history table: date, tournament name, format, rating, position, score. Start-to-final rating summary if multiple snapshots.
- `auth/setup.html` — Credential setup instructions: explanation of auth model, step-by-step guide for installing Cookie Helper extension and configuring .env.
- `admin/login.html` — Simple password form for admin panel.
- `admin/dashboard.html` — Admin dashboard: sync overview (last run, club count), per-club status table with step badges, game archive progress bars with auto-refresh (5s meta tag), error details.
- `admin/clubs.html` — Watched clubs management: add club form, remove button per club.

## Constraints

- MUST use Bootstrap 5.3 via CDN (no build step).
- MUST extend `base.html` for all pages.
- MUST display user-facing text in English only.
- MUST NOT contain JavaScript build steps or framework bundles beyond Bootstrap's bundle.

## Guidance

- Club sub-nav tabs SHOULD show a lock icon for auth-required sections when the user is not authenticated.
- Admin dashboard SHOULD auto-refresh every 5 seconds while any sync (Phase 1 or Phase 2) is running.
- Card grid layout is preferred for sparse data (overview, records); tables for dense tabular data.
